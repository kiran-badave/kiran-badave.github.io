## 📝 How to Use

### Step 1: Open the Template
```
https://kiran-badave.github.io/cover-letter.html
```
Or from portfolio homepage: Click "✉️ Cover Letter" button

### Step 2: Customize Content

**Editable Sections:**
1. **Recipient Info**
   - Hiring Manager name
   - Company name
   - Company address

2. **Subject Line**
   - Position title
   - Job ID
   - Department

3. **Salutation**
   - "Dear Hiring Manager" or specific name

4. **Letter Body** (5 paragraphs)
   - Opening & position interest
   - Current role & achievements
   - Relevant skills & experience
   - Why this company
   - Closing statement

5. **Closing**
   - "Sincerely" or other closing

### Step 3: Edit Instructions

**To Edit:**
1. Click on any text (it will highlight in light blue)
2. Type your changes
3. Click outside to save

**Visual Feedback:**
- Hover: Light blue background
- Focus: Blue outline + light blue background
- Edited: Changes saved automatically

### Step 4: Print or Save

**Option 1: Print**
1. Click "🖨️ Print Cover Letter" button
2. Or press Ctrl/Cmd + P
3. Select printer
4. Print

**Option 2: Save as PDF**
1. Click "🖨️ Print Cover Letter" button
2. In print dialog, select "Save as PDF"
3. Choose location
4. Save

### Step 5: Reset if Needed
- Click "🔄 Reset Template" to restore original content
- Confirms before resetting

### Letter Body Structure

**Paragraph 1: Opening (3-4 lines)**
- Position you're applying for
- How you found the job
- Brief overview of qualifications
- Enthusiasm for opportunity

**Paragraph 2: Current Role (4-5 lines)**
- Current position and company
- Key responsibilities
- Major achievements
- Relevant technologies

**Paragraph 3: Skills & Experience (4-5 lines)**
- Relevant technical skills
- Tools and technologies
- Methodologies
- Alignment with job requirements

**Paragraph 4: Why This Company (3-4 lines)**
- What excites you about the company
- How you can contribute
- Alignment with company values
- Specific interests

**Paragraph 5: Closing (2-3 lines)**
- Request for interview
- Thank you
- Availability

### Closing
```
Sincerely,
[Signature Space]
Kiran Badave

Enclosure: Resume/CV
```

## 💡 Customization Tips

### For Different Companies

**Tech Startups:**
- Emphasize innovation and agility
- Highlight modern tech stack
- Show passion for product
- Mention startup experience

**Product Companies (Microsoft, Google, etc.):**
- Focus on scale and impact
- Highlight ownership (DRI)
- Emphasize system design
- Show AI/ML interest

**Financial Services (BNY, JPMorgan, etc.):**
- Emphasize security and reliability
- Highlight compliance experience
- Show attention to detail
- Mention financial domain knowledge

**Consulting Firms:**
- Highlight problem-solving
- Show client interaction
- Emphasize adaptability
- Mention diverse project experience

### Content Customization

**Opening Paragraph:**
```
Generic:
"I am writing to express my interest in the [Position]..."

Better:
"I am excited to apply for the [Position] at [Company], where I can leverage my [X] years of experience in [specific skill] to contribute to [specific team/project]."
```

**Achievement Paragraphs:**
```
Generic:
"I have experience with React and Java."

Better:
"In my current role, I architected a scalable React-based system that reduced development time by 30% and improved user experience for 10,000+ users."
```

**Why This Company:**
```
Generic:
"I am interested in your company because it's a leader in the industry."

Better:
"I am particularly drawn to [Company]'s commitment to [specific initiative/value], and I'm excited about the opportunity to contribute to [specific project/team] using my expertise in [relevant skill]."
```

## 📊 Best Practices

### Content Guidelines

**DO:**
- ✅ Keep it to 1 page
- ✅ Use specific examples
- ✅ Quantify achievements
- ✅ Tailor to each job
- ✅ Show enthusiasm
- ✅ Proofread carefully

**DON'T:**
- ❌ Exceed 1 page
- ❌ Repeat resume content
- ✅ Use generic templates
- ❌ Include salary expectations
- ❌ Use informal language
- ❌ Have typos or errors

### Writing Tips

**Strong Action Verbs:**
- Architected, Designed, Developed
- Implemented, Optimized, Enhanced
- Led, Mentored, Collaborated
- Achieved, Delivered, Improved

**Quantify Impact:**
- "Reduced development time by 30%"
- "Improved performance by 40%"
- "Led team of 4 engineers"
- "Served 10,000+ users"

**Show Alignment:**
- Match job requirements
- Use keywords from JD
- Highlight relevant experience
- Show cultural fit

## 🆘 Troubleshooting

### Issue: Text Not Editable

**Solution:**
1. Ensure JavaScript is enabled
2. Click directly on text (not margins)
3. Try different browser
4. Refresh page

### Issue: Print Layout Broken

**Solution:**
1. Use Chrome or Edge for best results
2. Check print preview before printing
3. Ensure scale is 100%
4. Try "Save as PDF" instead

### Issue: Content Too Long

**Solution:**
1. Reduce paragraph length
2. Combine similar points
3. Remove less relevant details
4. Use more concise language

### Issue: Lost Changes

**Solution:**
1. Changes are not auto-saved to file
2. Print or save as PDF to preserve
3. Copy text to clipboard as backup
4. Use reset button to start over
